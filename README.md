## 📖 About

**Apex Gum** is a modern e-commerce website built on Shopify, designed to showcase and sell premium gum products[cite:51]. This repository contains development files and documentation for the project.

> 🔐 **Note:** The live site is currently password-protected during development phase[page:1].
